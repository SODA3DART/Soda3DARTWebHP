# Soda3DARTWebHP

崇城大学芸術学部美術学科3Dアートコースのポートフォリオ・情報発信ウェブサイトです。

## プロジェクト概要

このウェブサイトは、3Dアートコースの学生作品、イベント情報、コース紹介などを発信するために制作されています。HTML、CSS、JavaScript（バニラ）を中心に構築されており、軽量かつ高速な動作を目指しています。

## ディレクトリ構成

- `index.html`: トップページ。最新ニュース、コース紹介、ギャラリーへのリンクなどが含まれます。
- `news_event.html`: ニュースとイベントの統合ページ。すべてのニュース記事がここに集約されます。
- `gallery.html`: 学生作品のギャラリーページ。
- `courseinfo.html`: カリキュラムや教員紹介などのコース詳細情報。
- `css/`: スタイルシートが格納されています。
- `js/`: JavaScriptファイルが格納されています。
- `images/`: ウェブサイトで使用される画像アセット。

## 主な機能

- **ニュース配信**: `news_event.html`にデータを集約し、トップページには最新3件を動的に表示します。
- **ディープリンク**: トップページのニュースから、`news_event.html`の該当記事へ直接遷移し、自動的に展開・スクロール表示します。
- **レスポンシブデザイン**: スマートフォンやタブレットなどのモバイルデバイスにも対応しています。
- **XR/3D対応**: 一部のコンテンツではWebXRやThree.jsを用いた3D表現が含まれています。

## 開発・更新ガイド

### ニュースの追加方法

1. `news_event.html`を開きます。
2. `newsData`配列（JavaScript内）に新しいオブジェクトを追加します。
3. `id`は既存の最大値+1を設定してください。
4. `index.html`の`getDefaultNewsData()`関数にも、最新の重要なニュースを追加することをお勧めします（ロード失敗時のフォールバック用）。

### 画像の追加

- `images/`ディレクトリ内の適切なサブフォルダに画像を配置してください。
- 可能な限りWebPなどの軽量なフォーマットを使用してください。

## ライセンス

このプロジェクトのリソース（画像、テキストなど）の著作権は崇城大学芸術学部美術学科3Dアートコースに帰属します。
